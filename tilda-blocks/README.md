## Как перенести на Tilda

### 1. Подготовка страницы
- Создайте новую страницу в Tilda
- Выберите шаблон или пустую страницу
- Установите тёмный фон страницы: **#1b1b1b**

### 2. Добавление блоков T123
- Добавьте блок **Zero Block (T123)** — в поиске блоков введите "T123" или "Zero"
- В каждом блоке откройте настройки → **HTML-код**
- Скопируйте содержимое соответствующего HTML-файла и вставьте в блок

### 3. Изображения (обязательно)
У каждого изображения в Tilda свой URL (разные ID, имена файлов могут отличаться). Используйте **конфиг + скрипт** для автоматической замены.

**Шаг 1.** Откройте `tilda-images-config.json` и впишите в него **полные URL** из галереи Tilda:
- Откройте страницу с галереей в браузере
- F12 → выберите нужное изображение → найдите элемент с `data-original="https://..."`
- Или правый клик по изображению → «Копировать адрес изображения»
- Вставьте URL в соответствующее поле конфига (ключ — исходное имя файла)

**Шаг 2.** Запустите скрипт:  
`node apply-tilda-images.js`

Скрипт заменяет все плейсхолдеры во всех HTML-файлах на URL из конфига.

**Список файлов для сопоставления в конфиге:**
header_logo.png, minister_1–3.png, award_1–6.png, pattern_training.png, pattern_families.png, project_1–3.png, about_image.png, team_1–4.png, review_logo_1–4.png, review_scan_1–4.png, client_1–10.png, npm_model_nobg.png, vpm_model_nobg.png

### 4. Шрифты
В блоках используются шрифты из библиотеки Tilda:
- **BebasNeueCustom** — для заголовков (h1, h2, h3, h4)
- **OnestCustom** — для основного текста

Убедитесь, что шрифты OnestCustom и BebasNeueCustom загружены в Tilda (Настройки → Шрифты → Дополнительные шрифты).

### 5. Якорные ссылки
В коде используются якоря для навигации:
- `#services` — Компетенции
- `#training` — Обучение
- `#agr` — 3D моделирование
- `#benefits` — ROI и эффективность
- `#cases` — Реализованные проекты
- `#contact` — Форма обратной связи

Убедитесь, что блоки с этими ID присутствуют на странице.

### 6. Формы и отправка на welcome@bimpro.ru (сервис Tilda)
В блоках **06**, **13** и **17** формы отправляют данные в приёмник Tilda (`https://forms.tilda.ws/record/`). Чтобы заявки приходили на **welcome@bimpro.ru** (подключён в Настройки сайта → Формы → Подключенные сервисы):

**Настройка (один раз):**
1. В Tilda добавьте на страницу блок **«Форма»** (Форма приема данных) с полями **Имя** и **Телефон**.
2. Во вкладке **Контент** этого блока выберите сервис **Email: welcome@bimpro.ru**. Сохраните и опубликуйте страницу.
3. Откройте опубликованную страницу в браузере → **Просмотр кода страницы** (Ctrl+U). Найдите форму (поиск по `forms.tilda.ws` или `formid`). Скопируйте значение **formid** (из атрибута `name="formid"` или id блока формы).
4. В каждом Zero Block с формой (файлы 06, 13, 17) в коде замените **ВСТАВЬТЕ_FORMID** на скопированный formid в строке  
   `value="ВСТАВЬТЕ_FORMID"`  
   у скрытого поля формы. Сохраните блоки в Tilda.

Кнопки отправки используют программную отправку формы (`form.submit()`), чтобы обойти ограничения Tilda. Во всех трёх формах подставьте **один и тот же** formid от блока «Форма», настроенного на welcome@bimpro.ru.

## Дополнительные стили

Файл `_shared-styles.css` содержит общие CSS-переменные. Его можно добавить в **Настройки страницы → Дополнительно → Свой CSS** для единообразия цветов и шрифтов.

## Ограничения Tilda

- **Модальные окна** (подробности услуг, отзывы при клике) в HTML-версии отключены — при клике на карточку ничего не происходит. Для интерактивности можно использовать всплывающие окна Tilda или ссылки на отдельные страницы.
- **Выпадающее меню «Услуги»** в шапке упрощено — все пункты отображаются как одна ссылка. Для полного меню используйте встроенный блок меню Tilda.
- **Анимации** (Framer Motion) заменены на CSS-анимации где возможно.
